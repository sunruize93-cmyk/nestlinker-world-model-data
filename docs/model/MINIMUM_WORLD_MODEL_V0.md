# 最小可运行世界模型 v0

## 结论

v0 已跑通，但结论仅为 **机制可运行、尚未校准**。它能把真实历史价格带、合成租客约束和现实核验状态组合成可重复的行动路径；不能判断某套房安全、合同有效、押金会返还或外国租客一定能租到房。

## 深模块接口

外部 seam 只有两个纯函数：

- `run_minimum_world_model(market_payload, scenario)`：运行单一情景。
- `run_scenario_matrix(market_payload, specification)`：排序情景、为相同市场分配共同随机流并生成确定性报告。

CLI `minimum-world-model` 是文件适配器：先校验已发布 snapshot 的 manifest、schema 与哈希，并只接受 `seoul-rental-price-files / derived_observed / historical_time_sliced_distribution`，再读取情景文件。输出同时绑定数据文件 SHA-256、manifest SHA-256、manifest 输入 commit、情景文件 SHA-256 和模型代码 SHA-256。

## 状态与标签

| 内容 | 标签 | 含义 |
| --- | --- | --- |
| 2024-08 区/月/房型/租赁类型价格分位带 | `observed` | 来源为已发布的 `derived_observed` 聚合，不是实时房源 |
| 租客预算、入住周、临时住房约束 | `synthetic` | 测试档案，不是真人数据 |
| 权属、权利负担、保证资格、合同条款状态 | `synthetic` | 演练状态，不表示真实房屋已核验 |
| 最低可负担比例与核验耗时 | `modeled` | 未经真人结果校准的产品政策参数 |
| 可负担比例、押金暴露超限比例 | `modeled` | 历史聚合分位带上的压力测试代理，不是现实结果概率 |
| 分位带插值产生的价格 | `synthetic` | 押金和月租边际分布独立抽样，不保留二者联合分布，也不对应真实挂牌或合同 |

## 机制门槛与安全状态

`mechanismGate` 只检查市场可负担性压力代理、合成押金 P95 压力代理、演练中的核验状态和临时住房退路。它不能验证具体候选房的现金硬上限，也不能代替完整安全目标。

完整 `safetyGate.passes` 固定为 `null`，状态为 `unknown_missing_outcome_calibration`，并列出缺失的 `R_D`、`R_C` 和 `P(H)`。只有获得 #15 的真人结果标签并完成校准后，才允许讨论完整安全门槛是否通过。

## 安全优先行动顺序

1. 核验冲突时，升级给持牌专业人员。
2. 核验未完成且入住迫近时，只允许使用时间和成本均在用户上限内的临时住房，同时继续核验。
3. 无可负担退路时，返回 `no_safe_path_adjust_deadline_or_fallback`，不强推成交。
4. 核验完整后，预算或押金暴露代理不满足门槛时调整预算/市场约束。
5. 所有门槛通过后也只进入 `proceed_to_human_contract_review`，永不直接输出“签约”。

## 固定情景结果

情景矩阵包含冠岳区和麻浦区、两档预算、1 周/8 周入住窗口，以及一个权利负担冲突探针；每个情景运行 5,000 次固定 seed 抽样。

| 行动 | 情景数 | 解释 |
| --- | ---: | --- |
| `adjust_budget_or_market_constraints` | 2 | 核验完整，但低预算下押金暴露和可负担门槛未通过 |
| `use_bounded_temporary_housing_and_verify` | 4 | 入住只剩 1 周且合同条款未核验，临时住房退路在上限内 |
| `escalate_to_licensed_professional` | 1 | 权利负担证据冲突 |
| `proceed_to_human_contract_review` | 2 | 代理门槛通过，但仍须人工现实复核 |

共同随机流下，低预算组的押金暴露超限代理为冠岳区 41.78%、麻浦区 38.34%；高预算组为 0%。这些数字只说明在本次合成价格压力测试里，预算上限如何影响规则输出，不能解读为押金损失概率。冠岳区与麻浦区合成押金 P95 分别为 7,402.46 万韩元与 8,224.17 万韩元；它们来自分位带外推，不是市场预测。由于公开聚合只提供边际分位数，v0 独立抽取押金和月租，不能用于推断二者的真实组合可负担性。

## 已验证不变量

- 相同输入与 seed 得到逐字段相同结果。
- 调换情景文件顺序不改变输出。
- 相同市场的预算反事实共享抽样，避免随机噪声伪造单调性。
- 提高最大押金暴露上限不会提高超限比例。
- 缺失或冲突的强制核验不能被速度、便利或预算优势抵消。
- 已完成的核验不会继续占用未来核验时间。
- 非法预算、无序分位数、小样本市场单元格和非法核验状态会被拒绝。
- profile、市场选择、核验状态、政策和随机参数使用严格白名单；scenario ID 只能使用不含联系方式的短 slug；未知字段会被拒绝，避免把个人信息写进结果。

## 当前缺口

v0 没有挂牌可得性、外国人被拒、核验真实结果、合同争议或押金返还标签，因此不能计算目标函数中的真实 `R_D`、`R_C`、住房连续性概率或获得住房概率。下一步不是继续调规则分数，而是完成决策图 #15 的最小化事件契约，并经过韩国隐私与住房法律专业审查后收集真人结果。
